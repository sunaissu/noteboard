Noteboard implementation review
11 October 2026

Top, bottom, left, and right properties now render the same shared sections. Chrome compared their actual button/input/select inventories for a mixed selection. Horizontal panels scroll and adapt to narrow widths. The mobile zoom control no longer overlaps the wrapped bottom toolbar.

Shared labels now use Y.Text, active typing publishes before blur, stale updates preserve peer objects and unrelated fields, and supplied collaborative history scopes undo to local edits. Navigation is local by default. Added object search, a board overview, session viewpoints, clean region-aware exports, shared upload/paste admission checks, text recovery notices, and keyboard context menus.

Validation: npm test passes 42 tests; type check, CJS/ESM/type builds, playground build, and package dry-run pass. Runtime npm audit reports 0 vulnerabilities. Chrome checks cover panel parity, live text, peer caret shifts, viewport-independent exports, selected exports, search, embedded context menus, rejected image paste, deleted-object draft recovery, and light/dark desktop/mobile layouts.

Release status: do not roll this out as an uncoordinated patch to existing shared boards. The text schema and default navigation behavior changed. Back up and migrate the authoritative Yjs document with migrateNoteboardText, persist it, and admit only updated clients. Pass binding.history to enable scoped collaborative undo. Package versions were not changed and no npm release or host deployment was performed.

Limits: local tests simulate peers and disconnected replicas; the production provider, persistence layer, account/session presence, and multi-device reconnect behavior were not tested. Browser QA uses headless Chrome, not a Safari/Firefox or physical touch/IME matrix.

Detailed audit status

NBD-R01 [USER; P1] Investigate the reported shared-cursor experience
  PARTIAL — concurrent-label/caret scenarios pass locally; the reported deployed two-user session was not connected or reproduced end-to-end.

NBD-R02 [CODE; P1] Concurrent text editing replaces whole strings
  IMPLEMENTED — shared text uses Y.Text and stale edits rebase.

NBD-R03 [CODE; P1] Active typing is absent from shared state until commit
  IMPLEMENTED — text publishes on input, with composition protected.

NBD-R04 [RISK; P1] A stale board snapshot can delete a remote object
  IMPLEMENTED — unseen peer objects are not deleted by stale snapshots.

NBD-R05 [RISK; P1] Stale edits can restore old properties and reorder remote work
  IMPLEMENTED for stale snapshot preservation — unchanged fields and unchanged relative order are retained. Insert/delete/move operations update affected Y.Array entries; same-object concurrent move semantics remain Yjs ordering.

NBD-R06 [CODE; P1] Undo replays an entire board snapshot
  IMPLEMENTED — supplied collaborative history tracks local transactions.

NBD-R07 [CODE; P1] A remote deletion silently discards the active text edit
  IMPLEMENTED — deletion/lock during editing retains text in a recovery notice when editing attempts to commit.

NBD-R08 [RISK; P2] A newly locked object can still be resized by an active drag
  IMPLEMENTED — ongoing single-element resize rechecks locking.

NBD-R09 [CODE; P2] Resizing pen strokes removes pressure values
  IMPLEMENTED — resized pen points retain pressure.

NBD-R10 [CODE; P2] Text bounds ignore some text styles
  PARTIAL — text commit measures font weight/style and line height; every geometry-changing property path is not certified.

NBD-R11 [CODE; P2] The text editor overlay loses object geometry
  PARTIAL — overlay follows object position/angle and standalone alignment; rotated multiline/shape alignment needs a broader browser matrix.

NBD-R12 [CODE; P2] Current raster export captures the display canvas
  IMPLEMENTED — dedicated content export is independent of viewport, grid, and selection overlays.

NBD-R13 [CODE; P2] JPEG output differs between the toolbar and public API
  IMPLEMENTED — toolbar and public API use the same JPEG background path.

NBD-R14 [CODE; P2] Context menus are positioned using the wrong coordinate space
  IMPLEMENTED — container-relative, clamped context menus.

NBD-R15 [CODE; P2] Shape shortcuts also respond to modified browser commands
  IMPLEMENTED — modified/composing shortcut keys do not select shapes.

NBD-R16 [RISK; P2] Async image and JSON import can outlive edit permission
  IMPLEMENTED — image/JSON callbacks check current permission and import generation.

NBD-R17 [GAP; P1] Image insertion needs admission checks and visible failure handling
  IMPLEMENTED — uploads/pastes share format, byte, and decoded-pixel limits plus visible failure messages.

12 October 2026 properties and scrolling investigation

Reproduced the report in a tall host page with real Chrome wheel input: top properties measured 360 CSS pixels; a 300-pixel canvas wheel gesture also moved the page 300 pixels, and repeated panel wheel gestures moved the page 900 pixels. React's delegated wheel listener could not cancel the browser default. The native listener previously cancelled only Ctrl/Command zoom.

Top/bottom panels now use category tabs and horizontal control strips instead of stacking tall property sections. Measured desktop appearance height is about 164 pixels; narrow layouts remain capped at 220. Side inspectors retain vertical scrolling, and the same property fields are available in each orientation. Keyboard tabs use arrows/Home/End and scroll only their own strip. Top controls leave room for Settings. Toolbar offsets and zoom placement use measured panel/toolbar sizes, preventing collisions when panels share an edge or collapse.

A native nonpassive wheel listener cancels canvas default scrolling while preserving React pan/zoom. Nested scrollable controls retain their native scrolling; their edges do not pass wheel input to the page. Horizontal strips map vertical wheel input to horizontal movement. Line/page delta modes and shifted trackpad deltaX are handled. Wheel input outside the board still scrolls the host page, and read-only boards still navigate. This changes wheel behavior, not touch/pinch support.

Validation: npm test passes 50 tests with package type/build checks. qa/interaction-review.cjs passes real wheel checks, read-only navigation, keyboard categories, desktop/mobile bounds, panel collapse and same-edge overlap assertions, with no passive-listener warnings or uncaught page errors. qa/review.cjs passes the existing property-field parity, collaboration, editing and export regressions. npm run playground:build passes.
